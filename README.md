# Recruitment Platform

Online recruitment platform based on Microservices Architecture
with AI-assisted resume parsing and CV-Job matching.

## Technical Baseline

- Java 25
- Spring Boot 4.0.8
- Spring Cloud 2025.1.3
- Spring AI 2.0.1
- React
- MySQL
- MongoDB
- Kafka
- MinIO
- Redis
- Docker Compose

## Services

- api-gateway
- identity-service
- candidate-service
- employer-service
- job-service
- resume-service
- recruitment-service
- matching-service
- notification-service
- web-app
